# pp_core

`pp_core` contains the fixed-lookahead Pure Pursuit baseline used by the benchmark suite.

## Files

- `pp_core/pure_pursuit_node.py`: controller node
- `config/pure_pursuit.yaml`: default controller parameters
- `config/pure_pursuit_benchmark.yaml`: benchmark baseline parameters
- `racelines/`: bundled baseline racelines

For review-time reproduction, the workspace-level scripts configure this package automatically.
