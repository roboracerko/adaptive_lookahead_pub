# Reference Results

This directory contains bundled summaries used to sanity-check reproduced runs.

## Included Summaries

- `results/main_benchmark/paper_reference_values.csv`

## Intended Use

1. Run the benchmark scripts.
2. Aggregate the outputs with `analysis/compute_stats.py`.
3. Compare the success-rate and runtime summaries against the bundled CSV.

## Caution

This anonymized package intentionally avoids submission-specific wording in the result summaries.
